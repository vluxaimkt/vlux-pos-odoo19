# VLUX Facturación V0.1

Base instalable para Odoo 19 Community. Incluye modelo fiscal, estados, auditoría, prevención de duplicados, token público y PAC simulador.

Esta versión no emite CFDI real. No incluye todavía portal público, catálogos SAT, CSD, XML CFDI 4.0, timbrado ni cancelación real.

Instalación: extraer `vlux_facturacion` en `C:\Odoo\custom_addons`, reiniciar Odoo, actualizar lista de aplicaciones e instalar `VLUX Facturación`.
